# Claude Code mods and terminal ricing: community mods catalog (as of 2026-10-14)

Scope and method. "Mod" = a Claude Code plugin whose `hooks/hooks.json` names a JS/TS module (function hooks), launched publicly on 2026-10-01 for Claude Code 2.1.287+. Primary data: the karanb192 list's own scan file [data/mods.json](https://github.com/karanb192/awesome-claude-code-mods/blob/main/data/mods.json) (generated 2026-10-13T03:54Z, validated against Claude Code 2.1.296), read from a shallow clone (no code run); ~135 mod READMEs read via raw.githubusercontent.com; release-tag counts via `git ls-remote --tags` on 2026-10-14. GitHub's REST/search API and github.com HTML were blocked by this environment's egress proxy (WebFetch could reach a few github.com pages). All dates are 2026 unless stated. "Wow" ratings (1-5) and "setup effort" are my own assessments, not sourced facts. Surface vocabulary used below (derived from the scan's `draws`/`calls`/`events` fields): pane (side pane, `Pane`/`$.ui.open`), band (`AbovePrompt`, the strip above the prompt), status (`$.ui.status`), toast (`$.ui.toast`), slash (`command.run`), tool hook (`tool.call`/`tool.check`/`classic.*`), prompt hook (`prompt.*`), transcript (rewrites `AssistantMessage`/`ToolUse`/etc.), spinner, prompt hint, session mode (prompt footer), pixels (`$.ui.blit`), audio (`$.audio.*`).

### Inferences
- The list is best used as a searchable index plus security footprint, not as a quality ranking: 52% of mods sit in 0-star repos, and stars are per hosting repo (big products like RuView/ruflo dominate star sorting).
- The Featured six are the closest thing to an editorial "best of", and they skew toward visual/ricing mods (image thumbnails, rich transcript rendering, live dashboard, file tree, prompt rail) plus one cost guard.
- The reach/sees columns are uniquely useful for a "ricer": cosmetic mods can be filtered to L0-L1 (no process spawning, no network).

## 2. Per-mod deep dive: surface, what it shows, install, dependencies/platforms, maturity, media (with wow rating)

### Takeaway
I deep-dived ~135 mods (all 6 Featured, the banner mod, the top-starred dedicated mod repos, all Anthropic-directory mods at summary level, every mod named in third-party roundups, and the most visually distinctive mods found by a keyword scan of all 3,836 descriptions). Almost all install with two commands (`/plugin marketplace add owner/repo` then `/plugin install name@marketplace`); the real friction is terminal capability (pixel graphics only in kitty/Ghostty, panes need fullscreen and width), macOS-only media integrations, and extra binaries (yt-dlp, ffmpeg, TeX, Homebrew taps). Maturity is uniformly young (most repos created 2026-10-02 or later; release tags range 0-53).

### Inferences
- The dominant install pattern is uniform and cheap (two commands), so "install effort" is really about terminal capability: anything drawing true pixels (`$.ui.blit`, image elements) looks best in Ghostty or kitty, degrades to half-blocks elsewhere, and loses images inside tmux; panes want fullscreen and 110-144+ columns.
- Several early-access mods (Mindful-Claude, cc-arcade, hyday-pet, Arunjay4213's set) still document the `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` opt-in; that is harmless on 2.1.287+ except for mods that deliberately activate only when the variable is exactly `1` (compact-adviser, Firstmate Calm), which may silently do nothing unless the variable is set.
- Maturity signals are thin everywhere: only a handful of mods have double-digit release tags (terminal-browser 53, prismantis 36, pokemon 20, skins 16, project-sentinel 16, cctop 11, prompt-rail 10). For a "rice", those are the safer bets.
- Star counts for fast-jev-compaction (7,606 stars, one day of pushes) and caliber-jev-compaction (1,303) are anomalous relative to activity; they should not be read as popularity of a mod.

### Gaps
- Open-issue counts, release notes and commit counts per mod repo could not be collected (GitHub API/HTML blocked); tags were used as the only maturity proxy.
- Not every mod in multi-mod collections (baselane 199, gobworks 118, widgets 97, whyashthakker 70, KilimcininKorOglu 53) was opened individually.
- Media links were extracted from READMEs, not viewed; I did not verify that each GIF still loads.
- No mod was installed or run (constraint), so runtime behavior, performance and visual quality are unverified; wow ratings rely on READMEs and media descriptions.
- Install commands for some mods (fables, katzensteg, ruview-live, session-band) were not fully stated in the READMEs I parsed.

## 3. What other mods and mod sources exist outside that list? (other catalogs, marketplaces, npm, other awesome lists, notable 2026 releases)

### Takeaway
Mods arrived via a fast timeline (proposal 2026-09-03, renamed "Claude Mods" 09-09, early access behind `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` from ~2.1.269, public launch 2026-10-01 in 2.1.287). Besides karanb192's scan there are at least five other catalogues (Singh-AP's curated list, FindMods.dev/DrishtantKaushal, whyashthakker's bundled collection, the voted claudemods.ai, Baselane's commit-pinned marketplace), Anthropic's own sources (built-ins, DevRel playground, the community marketplace mirror, the plugin directory), and a small npm footprint. Several well-known mods, including Anthropic's three playground examples, are absent from the scan.

## 4. What is popular or praised, which categories dominate, and what is missing?

### Takeaway
By volume, the ecosystem is dominated by awareness and cost tooling (git/PR/CI ~16%, usage/cost/limits ~14%, safety ~14%, tasks/plans ~13%, context/compaction ~11%), and by surface the band above the prompt and side panes are the canvases of choice. ### Inferences
- The "default rice" emerging from the data is a band (usage/context/cache) + a side pane (agents or files) + a transcript skin + one companion or game; that combination maps to the most praised mods (token-weather/wavy-usage, flightdeck/filetree, skins/prismantis/claudinator, pokemon/cc-arcade/Mindful-Claude).
- Utility categories are crowded and differentiated mostly by visual metaphor (weather, car gauges, health bars, Minecraft HUD, liquid rings); a new usage meter adds little unless it adds forecasting or attribution.
- The most valuable gaps for a "useful + insightful" terminal are: cost attribution per task/branch, coverage/CVE status panes, a pane layout manager to arrange multiple mods, session-to-GIF export for sharing rices, accessibility themes, and a robust cross-terminal image path (sixel/iTerm2 inline images) beyond kitty/Ghostty.

### Inferences
- A screenshot-worthy, still-useful rice (assessment): Ghostty or kitty, fullscreen, ≥144 columns; band: wavy-usage or token-weather-usage (usage/context/cache at a glance); pane: flightdeck (agents) or filetree (files); transcript: skins or claudinator (pick one; both restyle the same components) or prismantis for rich tables/diagrams; companion: pokemon or naruto; extras: image-view for pasted images and cc-arcade or Intermission for waits. Keep cosmetic picks at reach L0-L1 where possible and check `claude plugin validate` output before installing.
- Expect conflicts when stacking several transcript or spinner rewriters (skins, claudinator, prismantis, fm, acp-ui all hook the same rendering components), and when multiple mods compete for the single band above the prompt; Singh-AP's gallery shows three mods sharing the band and two sharing the status line in one session ([Singh-AP gallery](https://github.com/Singh-AP/awesome-claude-mods)), so sharing is possible but space is finite.
- The highest flex-to-effort ratio is in two-command, zero-dependency mods with pixel art (naruto, pokemon, pixelband, dopa-mode, clawd-buddy, galactic-battle); the highest absolute flex (Intermission, terminal-browser, wolfbud, ruview) costs specific terminals, binaries, keys or hardware.

### Gaps
- No mod was run, so frame rates, flicker, CPU use and how well showpieces coexist are unverified.
- Demo media were not opened; some GIFs may be mockups (e.g. claude-deck and dreeft show SVG renders, not captures; Singh-AP says its gallery is "Real captures").
- Several showpieces have 0-5 stars and 0-1 release tags, so longevity is uncertain; many are one-week-old repos.
