## YouTube: videos on Claude Code mods, status lines, hooks, customization, terminal setups and "my setup" workflows

### Takeaway
YouTube is flooded with mods coverage. StationX's review (data as of about 4 Oct 2026) covers 34 transcribed mods videos made in the preview month and the first days after the 1 Oct 2026 launch. It lists 11 more without transcripts (9 non-English, 2 Shorts). The best primary-ish watch is Anthropic's Thariq Shihipar on Latent Space. The most-viewed in StationX's set is Chase AI's (174k views). The most useful practical ones are Nate Herk, Mark Kashef and Mr. Cloud Book. StationX flags 8 of the 34 (about a quarter) as pre-launch (September preview) with setup steps that are now outdated. Status line videos are a smaller, older genre (2025 to 2026).

### Inferences
- For a "ricing" viewer, the most actionable order is: (1) Addy Osmani's written tutorial (below) or Code Nik's 100-second build for mechanics; (2) Nate Herk and Mark Kashef for ready-to-steal mod ideas; (3) Mr. Cloud Book or AI In View before installing third-party mods. The Latent Space/Thariq interview is the closest thing to an Anthropic "director's commentary".
- Videos are heavily "hype-first". StationX repeatedly flags overclaims: where mods render, cache duration, and security findings repeated without caveats. Treat any video's install steps as stale if it mentions `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS`.
- The All About AI status line video's topic (output styles and status line together) suggests it covers the 2025 launch of those features. Its date is unverified, so treat it as older.

### Gaps
- Publish dates and view counts could not be verified on YouTube (captcha redirect). The only view count available is StationX's 174k for Chase AI. No "my Claude Code setup" tour video from 2026 surfaced in searches restricted to youtube.com; setup tours were found only as blog posts.

- No Anthropic-produced mods video was found; StationX says none existed as of 4 Oct.

**Official / Anthropic-adjacent: baseline facts on mods**
- **Anthropic, "Customize Claude Code with mods" (1 Oct 2026; no author listed)**: mods are "small TypeScript functions" that hook events (tool calls, permission requests, screen drawing) and run before, after or instead of them. They can rewrite prompts, block, rewrite or retry tool calls, approve or deny permissions, redact secrets from tool output, and edit or replace UI (tool results, questions, buttons, inputs). Examples: sec-default (built-in, loads first on Team/Enterprise or managed machines, stops user mods overriding deny rules), a CI/CD status pane, production-config confirmation, and an audit-logging mod. `/diff` is now a mod you can disable or replace. Mods work in the CLI and desktop app, are **not sandboxed**, and should come from trusted sources only. Install via `/plugin` or the Claude directory, or ask Claude Code to write, install and hot-reload one — [claude.com blog](https://claude.com/blog/claude-code-mods) [fetched]
- **Addy Osmani, "Getting started with Claude Code mods" (claude.dev, 1 Oct 2026, 11-min read)** — [claude.dev](https://claude.dev/blog/getting-started-with-claude-code-mods/) [fetched]:
  - Requires v2.1.287+; on by default. The API can change between releases, and generated types in `.claude-plugin/types/` are authoritative. AGENTS.md support and `/diff` are built as mods (source in anthropics/claude-code `mods/`).
  - Anatomy: `.claude-plugin/plugin.json`; `hooks/hooks.json` with `{"modules": ["./x.mjs"]}`; `export function register(on)`; `on(event, matcher?, ($, e, next) => …)`. The three moves are observe, rewrite (`next({...e})`) and answer (`{deny:"…"}`). Events: tool calls, prompt submit, turn start/complete, session start/end, `command.run`, `ui.render`.
  - Builds **Token Weather**, a band above the prompt (`AbovePrompt`) showing forecast tiers ☀ Clear <25%, ☁ Cloudy, ☂ Showers, ☇ Storm, ↯ "Compact soon" ≥90%, a sparkline of the last 12 turns using ▁▂▃▄▅▆▇█, and a `▲ +98.3k last turn` delta. Data comes from `$.session.usage()` (same figures as the status line) and persists in `$.state` across hot reloads.
  - Dev loop: `claude --plugin-dir ./token-weather` (hot reload on save) → `claude plugin validate` → `claude plugin test` → share via `.claude-plugin/marketplace.json`, `claude plugin install … --scope user`, `/plugin marketplace add org/repo`.
  - Two more samples in anthropics/claude-code-playground: **Blast Radius** (holds `rm -rf`, `git reset --hard`, force pushes and migrations, dry-runs them, pane with Proceed [1] / Cancel [2]; "a safety net, not a permission system") and **Replay Theater** (records a turn's Edit/Write; press `r` or `/replay` to step through diffs).
  - Habits: use single-width symbols rather than emoji for alignment; read `e.props`; keep data in `$.state`; debug with `claude --debug`. Ideas: cost/rate-limit meter via `$.ui.status`, a `prompt.submit` hook adding team conventions, a pane of files read this session, a focus-timer toast, a kubectl/terraform guard.
- **Latent Space, "Claude Code's Next Era — Thariq Shihipar" (29 Sep 2026)**: mods started internally as "function hooks". They run in-process, can read session state (turns, tokens, messages), spawn forked sub-agents that reuse the prompt cache (cheap), and modify the UI, which shell hooks cannot. Example mods: quiz, assumption tracker, model router, mode selector, dashboard, next-steps supervisor. A Bun-team collaborator was involved. swyx raises the concern that unlimited customization confuses users and opinionated defaults are better; Thariq suggests skills can supply opinions — [Latent Space](https://www.latent.space/p/thariq) [fetched]
- **Version and timeline facts (per StationX)**: preview 3 to 14 Sep behind the `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` flag (now ignored); v2.1.287 launch on 1 Oct; v2.1.288 (2 Oct) adds `$.ui.selection()`; v2.1.289 (3 Oct) has marketplace and managed-machine fixes. ### Inferences
What made these go viral:
- **Dead-time reclaimed.** Every developer waits on agent turns. Games that start when Claude starts and stop when it needs you turn a shared frustration into play.
- **A social twist.** "Everyone in the lobby is also waiting for their Claude" is a relatable, meme-able line that invites replies and copycats.
- **Nostalgia and "it runs Doom" culture.** Doom, Tetris, MW2, StarCraft and Spotify Wrapped are instantly legible references.
- **"Claude built it for me" speed stories.** Examples: "in 9 minutes"; Firecrawl's "Claude said it was impossible".
- **Shareable artifacts.** Wrapped PNG cards and screenshots of pets and bosses are made to be posted.

For the user's own "flex" setup, the sources suggest a split: playful mods earn attention but are "completely useless" for productivity, per [Sharbel](https://sharbel.com/articles/claude-code-mods). Information-dense HUDs and guards earn lasting use. A tasteful rice combines one of each.
